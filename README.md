# Whitepapers (Portfolio Sample)

This is a redacted, anonymized sample from a growing portfolio of whitepapers I've written, designed, and built end to end. It is part of a larger portfolio demonstrating my abilities across research synthesis, persuasive writing, and frontend data visualization.

---

## What This Sample Demonstrates

### Writing & Narrative Strategy
Whitepapers turn a research-backed framework into something a business reader can actually act on. This sample showcases my ability to translate dense strategic and research content into a clear, structured narrative by distilling a multi-step methodology into a story stakeholders can follow, with supporting evidence woven in rather than simply added on.

### Data Visualization & Frontend Development
The elements in this report were built from scratch using HTML, CSS, and JavaScript. Key features include:

- **Animated stat counters** — key figures that count up on scroll, making core statistics land with impact
- **Structured framework components** — numbered process steps, driver/root-cause callouts, and accountability tiers built as reusable, styled components rather than plain paragraphs

### Design System & Frontend Engineering
The report is built on the same custom design system used across this portfolio (a shared color token library, typographic scale, and component architecture) extended here with new components specific to whitepaper content (framework steps, example callouts, source citations), all hand-coded in HTML, CSS, and JavaScript and hosted via GitHub Pages.

## A Note on Redaction
All identifying information — including organization name, program names, and any partner or client references — has been removed or approximated to protect confidentiality. Original external sources and citations remain linked. The structure, narrative approach, visual design, and technical implementation are my own work.
